## 已实测的性能

处理前按原冻结顺序选择第一份来源 V030，186.116667 秒、91,014,067 字节。固定顺序为 CPU 冷／热，再 CUDA 冷／热，每种一次；未按人评结果或测速挑片，也未重复试验选最好的一次。

计时从第一字节 HTTP 上传前开始，到完整 ZIP 下载并写入本地为止，包含排队、worker 全部处理、缓存发布及轮询。启动服务、预装依赖和本地模型文件准备、输入哈希预检、下载后审计另计。冷路径采用新 worker 与空应用结果缓存；没有清除操作系统磁盘缓存，模型对象首次加载包含在任务内。

CPU 请求 int8，实际 CTranslate2 后端为 CPU/int8_float32；CUDA 请求和实际后端均为 CUDA/float16。两条冷路径都验证了非静音语音、固定权重身份、真实模型加载及转写调用；热路径均零模型加载、零转写，缓存中的 ASR 耗时是原任务值，不冒充本次计算。

设备为 Ryzen 9 5900HX、16 逻辑处理器、16,558,161,920 字节物理内存、RTX 3070 Laptop 8 GiB、驱动 617.42，Python 3.11.9／Windows build 26300。ASR 固定 base 权重、4 CPU 线程及一个模型 worker。NVIDIA 的 8 GiB 是容量，未测显存峰值；表中为客户端、API、worker 及子进程的采样工作集之和，可能包含共享页，不能视为唯一物理 RAM。提交量与实际采样间隔另见 JSON；250 ms 是名义间隔，两条冷路径实际平均约 278–280 ms。

运行架构为真实 Uvicorn HTTP API、独立 Celery solo worker、filesystem broker 和 SQLite 状态库。测试使用独立数据目录、单 worker、顺序任务，主机其他应用未关闭；它不是 Redis／Docker 或独占空闲机器的基准。原生产 8200 服务和已有任务没有部署变更；测试进程已退出，两个测试端口已通过独占重绑确认释放。

ASR 组件分别用时 **24.392／9.961 秒**；镜头组件用时 **312.462／327.506 秒**。本例主要耗时仍在 CPU 镜头检测等阶段，整体没有观察到 CUDA 路径加速。两种精度产生 505／513 个词、107／115 个候选，恢复调用次数也不同；固定顺序、单样本和工作量差异不支持把耗时差解释为纯硬件因果效果，字数增加也不是准确率提高的证据。

四份下载 ZIP 的 SHA、每份 18 项 CRC／实际服务文件、Schema、四份上传原片、固定权重及运行依赖均核验。两条路径的归一化视频和七个输出视频逐字节一致；每份计划为 6×900＋184＝5584 帧。应用、基准脚本、依赖在运行前后保持相同字节，基准没有重试。此流程测量自动分析、候选生成与基础切片 ZIP；人工编辑、另存 MLT 和浏览器交互响应未并入该计时。

字符按 NFKC／casefold 处理，忽略空白与 Unicode 标点，保留数字／字母形式，不做语义改写。新三段不是三十源全文 CER；一个新视频的高 F1 不能覆盖旧九源的低召回，也不能证明多素材泛化。独立性为标注者确认，来源不同为用户说明，未宣称外部核验或双人逐帧金标准。没有用这些答案调阈值、ROI、排名或重选样本。

固定 20 词中，19 个可定位、1 个错词、0 个无法定位；按起止均在 ±0.3 秒且保留人工估读范围，15 通过、4 失败、0 不确定、1 不可测，确认通过率为 15/20。可定位的 38 个端点，按人工填写的中心时刻计算点 MAE **0.166702 秒**，最大绝对点误差 **0.755000 秒**；含估读范围的最大绝对误差上界 **0.760000 秒**。这些点指标只针对可定位子集；分类使用完整误差区间，跨越阈值保留不确定，不是置信区间。此处评原冻结全文 ASR 时间，精确片段另跑的 ASR 只用于 CER，未替换目标或时码。

词时刻原导出含 19 组起止和一个错词，但 19 项估读范围为空；用户随后明确补答统一为 ±0.005 秒。另建派生版只纳入这项补答及相应完成字段，原起止、错词、身份绑定和原件不改；原导出与派生版 SHA 同时保留。此统一范围是事后自报估计，不是逐词重复测量或外部验证。

原听写导出的标注者代号漏填，但三份实际文本、39 个切点、所有逐项已看／完成及独立确认均已填写。为避免重填，另建派生文件，仅由代理分配技术匿名编号并相应改变总完成字段；未改变答案、确认项或原导出时间，原件字节保留。该编号不是用户填写或验证的身份。公开数据同时记录原件与派生版 SHA；`blind_reference_sha256` 指向派生版。[新精度与词时间数据](evaluation/week7-validation-20261102/accuracy-new-reference-status.json)

## 新增字幕同步测量

本轮已回收同一旧成片中此前未测的 10 条字幕、20 个语音端点。按 ±0.3 秒及人工不确定范围判定，端点为 **12 通过、3 失败、3 不确定、2 个文件边缘无法夹定**；10 条字幕的排他分类为 **3 通过、3 失败、3 不确定、1 未完全可测**。两条字幕含文件边缘端点，其中一条同时归入“不确定”，边缘标记不另加分母。

18 个可夹定端点的平均绝对误差观察区间为 **[0.186940, 0.246385] 秒**，最大绝对误差上界为 **0.755 秒**；这不是点 MAE 或置信区间。三个明确失败均为字幕起点提前，误差区间分别为 [−0.755, −0.721667]、[−0.397979, −0.364646]、[−0.552, −0.518667] 秒。

显示端点来自实际解码画面的相邻帧；语音范围由人工独立听音填写，未用 ASR／VAD 代替。两个文件边缘没有片外相邻帧，保持无法夹定，绝不默认通过；原片上下文允许换算后的语音早于成片零点或晚于 EOF。旧三条校准记录未混入，本轮未修改字幕或视频；结论只限这一份旧成片，不能宣称全部字幕均在 0.3 秒内或具有多素材泛化效果。[字幕同步数据](evaluation/week7-validation-20261102/subtitle-reference-status.json)

## 工具与交付边界

新增显式 `CLIPFORGE_ASR_DEVICE=cpu|cuda` 和 `CLIPFORGE_ASR_COMPUTE_TYPE`，默认 CPU/int8；CUDA 默认 float16，另允许 int8_float16。设置不合法则拒绝，显式 CUDA 失败不会回退 CPU。运行参数进入模型对象缓存、结果缓存指纹和 ASR 元数据；实际设备由本轮 CTranslate2 观察记录另行验证。
