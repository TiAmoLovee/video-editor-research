# 第七周工程加固：PCM 末端与视频时间轴

2026-10-27。真实录制素材在当前默认 base／CPU 转写中触发 `Invalid Silero VAD interval for ASR coverage audit`。该源视频归一化后为 2624 帧、30 fps，时长 87.4666666667 秒；16 kHz PCM 向上取整为 1,399,467 个采样，末端为 87.4666875 秒。Silero 的末段恰好结束于 PCM 末端，比视频长 1/3 个采样，约 20.833 微秒。

修复只接受已经通过真实 PCM 长度及格式检查、等于该 PCM 末端、超出量小于一个采样的区间，将其转换到视频终点。原始 gate、调整前后值和样本数量进入版本化元数据；普通合法区间与原始音频、词条和原转写分段保持。一般越界、错误采样长度、非末端微小越界和词时间的严格检查继续拒绝错误。

63 项相关测试及 19 项独立内存检查通过。一次真实 base／CPU 补充转写用时 27.08 秒，得到 282 个词和 11 个句子，原严格 coverage、`combine_analysis`、Schema 和词句边界检查通过；未重跑镜头检测或归一化。该计时来自共享主机的工程复现，不是隔离性能基准、全应用 RTF 或人工质量通过率。具体数值见[公开工程证据](evaluation/week7-pcm-boundary-20261027.json)。

30 个原视频的评测使用独立冻结清单，区分 21 条开发已见与 9 条用户声明来自不同原片的新增素材。原始冷分析基线和所有失败保持；修复后材料通过逐组件兼容性校验复用本轮已测结果，并重建分析、候选和评分。分析元数据变化导致候选 ID 改变，必须记录新旧 ID 映射；只有精确范围、文字及句子来源、分数与排名、源媒体哈希和帧范围一致时才复用原预览。补充处理时间与原基线时间分别报告，不能拼成一次新的冷启动耗时。
