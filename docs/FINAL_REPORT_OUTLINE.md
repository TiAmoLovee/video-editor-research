## 已知缺陷章节至少包括

1. 默认规则首尾完整和接受率未达到参考，结尾完整是两评者共同主要问题；低 κ 显示任务主观性，也需讨论标注口径，不能将所有差异归因模型。
2. 镜头结果跨来源差异显著；开发已见、新来源样本少且不随机，不能泛化成全数据集性能。
3. 词时间存在四个超差及一个错词不可测；人工 ±0.005 秒为自报估读范围，无外部精度认证。
4. 十条字幕有三处明确起点提前，以及不确定/文件边缘不可夹定项；早期三条同样本校准不代表独立通过。
5. CPU/CUDA 冷路径均慢于参考，GPU 未改善该单来源总体耗时；镜头检测瓶颈仍需有对照的优化验证。
6. 完整 Docker 故障注入、第三方干净机复现、长真实素材同口径性能尚待完成；合成素材、组件测试与实际全流程证据分别陈述。
7. 新交付成片与预览出口均已加显式标识，本机实际MP4/ZIP及16帧可视抽样已验；元数据可被后处理删除，MLT 被编辑器另存再导出的行为仍需单独核验。盘点不等于许可审计通过。
8. 自动清理、处理中断恢复、多用户隔离等未实现能力按当前代码核验后列出，不承诺已交付。
