# 网页剪辑与导出

第五周导出工作台沿用 React、Ant Design 与现有任务页面。用户在候选旁点击“加入成片”，按上移／下移排列后保存剪辑版本；所有生成和下载均绑定页面明确显示的保存版本，不从当前评分或草稿自动重建。

## 使用流程

1. 在已成功且有候选记录的任务中选择片段，最多 100 条。分页或过滤候选时保留本任务的选择，切换任务时清空草稿。
2. 保存选择为统一 EDL。服务实测源媒体，创建新的不可变版本，不覆盖已有任务或成片。
3. 可从横屏保存版本创建固定中心裁切的 9:16 版本。竖屏是独立版本，字幕须使用该版本的布局。
4. 生成字幕，下载 SRT／ASS，或勾选带字幕导出 MP4／Shotcut 工程。字幕沿用保存转写，不代表已校正错字或完成真实人声同步验收。
5. 已保存版本、字幕、MP4 与 MLT 从服务器历史读取，刷新或重启后仍可继续下载。草稿尚未保存时不承诺跨刷新保留。

MP4 可直接下载播放。MLT 引用服务端的原归一化素材；在容器以外或其他电脑打开，需要同时下载源素材，并在 Shotcut 重新定位路径、安装工程所用字体。工程下载不包含素材副本。含音轨的单帧选段仍遵循已记录的 MLT 限制，改用同一 EDL 导出 MP4。

## 状态与恢复

创建接口仍是同步原型。媒体核验和 MP4 操作服务端预算为 90 秒，网页创建请求最多等待 120 秒；没有虚构后台进度百分比。页面显示当前正在核验／渲染，操作期间禁止连续创建。不自动重试 POST。

网络中断、超时、无效创建响应或服务端／网关 5xx 可能使结果无法确认。网页保留此任务的恢复状态，先读取已保存记录，再由用户核对版本和文件后继续，避免将断连当作尚未生成。任务或版本切换后，迟到响应不能替换当前任务的状态。收到成功 UUID 但后续读取失败时，恢复优先定位该版本。

## 历史接口

| 接口 | 内容 |
| --- | --- |
| `GET /tasks/{task}/edl?limit=10&offset=0` | 核验后的版本记录、画幅与精确候选顺序 |
| `GET /tasks/{task}/edl/{revision}/artifacts` | 该版本的字幕、MP4 与 MLT 记录 |

列表仅接收已完成的合法 UUID 目录，并调用既有读取器核验文件与来源。未完成目录不展示，损坏的完成记录计入不可读数量；不返回额外私有字段或原始路径。时间按带时区时间降序排列；列表最多扫描 500 个目录项、核验 100 个完成记录，超过返回明确错误。版本分页上限 50 条，offset 上限 500。历史读取可能核验较大媒体字节，网页按需读取，不随任务的三秒轮询反复加载。

下载链接由本任务与版本的严格 UUID、文件白名单构造，不使用服务端任意 URL。下载继续持有校验后的文件句柄，支持单段 HTTP 字节范围：正常范围返回 206，越界返回 416，读取不跨越所请求的末尾。多段或未知单位回退完整下载；当前没有强 ETag／日期验证值，带 If-Range 的请求也回退完整下载。网页播放器失败时仍提示下载查看。

## 本轮验证范围

前端行为测试覆盖跨页选择顺序、任务隔离、保存与导出绑定、横竖屏字幕隔离、连续点击、未知响应恢复及历史下载。新增服务测试覆盖真实读取器、分页排序、篡改／未完成记录、跨任务与路径防护。真实 Test3 历史只读回读与输入保持记录保存在工作区 `outputs/week5-web-export/`。

用户启动 8330 预览后，已通过真实网页完成选择、调整顺序、保存 EDL、生成字幕、导出 MLT 与带字幕 MP4。新的功能验证版本包含两条片段，共 1263 帧／42.1 秒；独立核对首尾与拼接前后画面，第 722 帧准确进入第二条片段。12 条字幕与两种导出均绑定该保存版本。原有 94 个任务文件保持原样；旧 EDL／SRT／MLT 的浏览器下载哈希与保存文件一致。此样本用于检验导出流程，不新增质量评分或人工接受标签。

Range 修复通过 11 项直接 ASGI 响应测试及 25 项现有接口回归，实际 HTTP 请求也取得正确的 206／32 字节／Content-Range。由 Codex 临时启动的修复版服务曾无法被右侧浏览器访问；用户随后通过 `Start-Week5Preview.ps1 -Port 8331 -VerifySeeking` 启动修复版，并完成真实浏览器拖动验收。42.1 秒成片的可拖动范围为 0–42.1 秒，原生播放器从 37.89 秒向后拖至 11.923057 秒，恢复播放后推进至 12.402686 秒，readyState 为 4，播放器无错误。此轮仅读取已保存成片，未新增 POST、模型调用、上传或渲染。实测记录与截图保存在 `outputs/week5-web-export/browser-verification/seeking.json` 和 `seeking-verified.jpg`，哈希记入同目录 `result.json`。8330 保留为已核验的原预览，8331 为本轮修复版预览。

本轮仍为本地预览接入，不等同于现有 8200 服务或 Docker 已升级，不等同于 GitHub 已发布。旧 Shotcut 保存核对、87 帧合成效果及完整 2180 帧真实渲染证据保留；网页新增 MLT 的此轮检查核对结构，未重复进行原生渲染。网页证据保存在工作区 `outputs/week5-web-export/browser-verification/`。
