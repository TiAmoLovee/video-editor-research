# 第二周成果与验收说明

记录日期：2026-09-22。请在 GitHub 切换到 `week2/mvp0` 分支查看，回到[仓库首页](../README.md)。

## 本周交付是什么

本周将第一周的调研推进为可运行的媒体处理原型：通过网页上传视频，由后台转为 H.264 / AAC、CFR 30 fps，按每段最多 900 帧切片，再通过网页下载。最后不足 30 秒的尾片保留。

这一步解决基础媒体流程；镜头检测、语音活动检测、转写、语义推荐和人工编辑仍是后续工作。当前 `clip_plan.json` 记录固定切片的帧边界，不等同于已经交付完整 EDL 编辑系统。

历史任务只存在于当前开发机的数据卷，不随 Git 克隆到其他电脑。新电脑演示需先用自己的素材提交任务。长视频任务仍在执行时，可查看已有结果，暂不重启服务或再提交大型任务。
