# 中文分句规则 v2

日期：2026-09-28。修复长度兜底把“智能”“抽空”等中文词语拆到两句的问题。ASR 模型的 word 有时仅为一个汉字；在模型词条之间切分仍可能破坏中文词语。

## 规则与数据边界

- 使用 jieba 0.42.1 默认词典，精确模式、HMM 关闭，不使用 Test3 定制词典、不补字、不改错字。
- 全文分词边界与原 ASR 词条边界同时满足时，才允许断句；英文连写、常见连接符和小数内部也保留完整。不会拆开一个原始模型词条。
- 句末标点优先；独立的闭引号/右括号归到前面的句子。词内停顿不会强行拆开词语。
- 词语之间停顿达到 1 秒可断句；达到 0.4 秒且前文至少 12 字时也可断句。
- 50 字、15 秒是软目标。到达目标时可向后寻找至少 0.1 秒的相邻停顿，最多额外 15 字或 3 秒；否则回看已有逗号/至少 0.15 秒停顿，再退到完整词语边界。单个不可拆单元若已超限，仍保留完整。
- 原始 words 的 ID、文字、概率、起止时间、顺序全部不变；每词仍恰好被一句引用。句子时间仍取成员词的最小开始、最大结束。不新增标点，也不把人工参考原文写入识别结果。
- `analyzer.parameters.sentence_rules.rule_version` 为 `2`，记录词典版本与全部规则。Schema 仍为 0.1.0 草案；旧任务保留原规则和结果。

这属于“词语边界保护 + 标点/停顿分组”，不是完整语义理解。词典可能误分未登录词或专名；语句仍可能在完整词语之间断得生硬。没有自然句界人工标签，所以不宣称句界准确率达标。

## 验证

- 133 项后端测试、Ruff、pip check 通过。新增真实 base/small 词条回归及引号、英文、小数、超长单元、软限制和空输入测试。
- 对已下载的 base 与 small 结果只重算分句：5→5、5→6。所有词条与时间不变，全部引用完整，新汇总通过契约校验；“智能”“抽空”在两版中都没有被拆开，small 的“小伙伴”也保持完整。
- small 结果中的“能来抽／空跟我们聊两句”改为同一句内的“能来抽空跟我们聊两句”。这不纠正“刘慈禧”“牵收会”等 ASR 错字，也不会降低已有 CER。
- 本地 small 模型完整流水线覆盖无音轨、静音、公开中文语音，契约、ZIP CRC 和独立下载一致性通过。队列为测试替身；新规则 Docker 验收待用户执行，前端未改未重跑。
- 证据：`samples/sentence_rule_verification.json`。测试中的词条夹具来自用户提供的两版 Test3 结果，没有放入原始视频。

## 不重新识别的预览

`backend/tests/integration_sentence_replay.py --asr 路径 --analysis 路径 --output 新文件路径` 可重算分句并输出预览报告。脚本只读原文件，输出必须为新文件；它不会修改服务任务、重新运行模型，也不会把预览冒充新任务结果。

## 部署

安装新增的 jieba 0.42.1，复测后重建。已启用 small 时继续使用 `docker compose -f compose.yaml -f compose.asr-small.yaml up -d --build`，否则只用 compose.yaml 会回到 base。重新上传 Test3；旧任务不自动更新。两个模型都适用新规则，无需重新下载模型。

本地分发的 wheel 是从 PyPI 官方 sdist 校验后原样构建的通用 Python wheel，来源与哈希记录在验证文件中。Docker/CI 根据 requirements-worker.txt 安装固定版本。组件参考：[jieba 官方项目](https://github.com/fxsjy/jieba)。
