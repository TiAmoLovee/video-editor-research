## 实测发现与处理

1. PCM 末端向上取整可比 CFR 视频长不到一个采样，触发严格 coverage 审计。修复只转换已核验的精确 PCM 末端，保留原 gate 和调整证明；一般越界及词时间检查不放宽。见 [工程说明](WEEK7_ENGINEERING.md) 与 [复现证据](evaluation/week7-pcm-boundary-20261027.json)。
2. V027 原片音轨先于视频结束：119.104 秒的 48 kHz 音轨对照 3575/30 秒视频，首个候选缺 3008 个采样（62.667 毫秒），原预览的音轨仅 29.637 秒，对照视频 29.700 秒。原 40 毫秒校验正确拒绝。补充 renderer 在原裁剪后按精确目标样本数补缺失尾静音并截齐，保留全部三个候选、声音和视频帧范围。修复后依然执行原严格校验。

原冷分析基线及失败保持，修复后仅逐组件核验复用本轮结果；117 份分析代码与基线一致，仅 ASR 文件变化。元数据变化导致候选 ID 改变，另记新旧 ID 映射。V027 的渲染补充另冻源码和收据，原失败预览、状态、耗时与证明均归档；没有重新转写或选片。原先部分发布的组属于旧批次，结果不得混入本批。

ASR 词覆盖诊断为：`suspect_coverage` 7 条、`clear` 23 条。这些是 VAD／ASR 不一致标记，并非 CER 或人工质量结论；本轮保留默认上限内的恢复逻辑，不按结果反复调参或剔除候选。

## 人评与统计门槛

A、B 分别独立看同一批片段，B 顺序固定反向。六项分别回答“是／否／不确定”，无预选；“愿意保留”独立填写。导出完整答案前，评者需确认独立观看。

全部六组、30 来源终态以及各非空组有效且无冲突的 A/B 完整答案齐备后，才汇总原始配对行计算三类 nominal `accept` Cohen κ，同时保留“不确定”和 yes-vs-rest 敏感性分析。各题项、每人首尾完整率、五项语义完整率、接受率及 21/9 分层分别报告。缺组、未完成或冲突时总体统计为 `null`，不平均六个组 κ。空组和缺失槽位不伪装为已完成人评。

共享主机上原分析与补充处理分别计时，未得到新冷启动或完整应用 RTF，不能据此宣称 CPU／GPU 性能目标达标。CER、镜头 F1 与误差阈值需要相应独立参考标注，本轮材料准备不替代这些测量，也不宣称整周评测已通过。
