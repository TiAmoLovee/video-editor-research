## 输入与输出约束

`boundary-context-review-v1` 从冻结分析和评分文件生成请求，绑定分析、候选、提示词及完整请求哈希。输入包含当前候选、前两句上下文、后文和至多 5 个合法已有延长候选。所有备选保持起点、原句前缀及原有 15–90 秒限制，内部句间隔不得超过 3 秒。不发送规则分、排名、人评标签、文件路径、视频或音频。

提示词单独保存在 `prompts/boundary/context-v1.txt`，明确转写为数据而非指令。模型返回结尾判断 complete / incomplete / uncertain、简短说明、1–3 处逐字原句引用及可选的已有候选 ID。至少引用一处候选内文字；推荐延长时还必须引用一处新增范围内的原文。拒绝改写引用、未知候选、任意新时间、分数字段、重复 JSON 键、缺失字段及截断响应。

通过校验只代表格式和引用正确，语义合理性仍待审阅；模型不替代人工反馈，不自动裁切、采用建议、重新评分或提升完整率。

## 调用约束

接收方固定为 `https://dashscope.aliyuncs.com/compatible-mode/v1/chat/completions`，模型 qwen-plus。最多 2 次，每次最多 512 输出 Token；最多尝试一次，无自动重试。逐条先验证请求哈希与调用方提供的授权哈希，全部通过才进入发送；先持久化尝试记录，再调用。超时或未知结果也不再次发送同一计划，第一条失败即停止本批后续调用。密钥由授权后的调用方提供，本模块不自行读取凭据或环境文件，不记录密钥及服务端错误原文。该路径未接入自动上传流程。
