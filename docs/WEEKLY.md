# ClipForge 每周工作记录

## 第二周：媒体流水线骨架与最小闭环

### 本周目标
完成“上传视频 → 后台处理 → 进度显示 → 下载切片”的最小流程。视频归一化为 CFR 30fps / H.264 / AAC，按每段 30 秒切片。

### 本周完成
- 使用 Git 命令将远程仓库克隆到本地。
- 核对当前分支、远程地址和提交历史。
- 创建第二周开发分支 week2/mvp0。
- 安装并验证 Python 3.11.9，创建项目独立环境 .venv，配置 Git 忽略规则。
- 新增 probe.py：接收视频路径，调用 FFprobe，将 JSON 输出解析为 Python 字典。
- 在本地运行 probe.py 验证 Sucai1.mp4：时长 41.266667 秒，分辨率 960×600，视频编码 HEVC，平均帧率 30 fps，音频编码 AAC、44.1 kHz、单声道。
- 当前完成基础信息读取；项目统一的 media_meta.json Schema、归一化转码和切片仍未实现。
