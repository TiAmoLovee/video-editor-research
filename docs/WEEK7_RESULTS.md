# 第七周真实双人评测结果（2026-11-02）

30 份原视频、六组、141 个实际片段的双人评价已回收并核验。默认规则所选片段的接受率为 A 55.32%、B 53.19%；首尾均完整率为 A 58.16%、B 36.88%。本轮补齐了真实人评证据，结果尚未达到任务书对应的完整性与接受率参考值。

## 回收与来源

原始导出共 12 份，A、B 各六组，全部核对冻结批次、组清单、片段哈希、题项、答案类型与独立确认。最初有 11 份完整，一份漏选一项；经明确询问后，由用户代 A 补答“不确定”。12 份原文件保持原始字节，有效统计输入为 **11 份原始完整导出＋1 份明确补答派生文件**。派生文件只改变漏项及两个完成状态字段；原导出时间保留，补答时间与新旧哈希另记，不伪称原浏览器导出已完整。

两位评者在导出时确认独立评价；这是评者确认及用户转述，未作外部独立核验。1692 个题项均有回答，缺失答案不自动记为“否”或“不确定”。A 正向、B 反向观看相同冻结片段；“愿意保留”始终独立作答，没有由其他题推算。

来源分母保持 30，计划 150 个槽位，实际 141 个片段，9 个未填槽位源于候选数量不足。原冷分析与补充处理中的失败记录保留，最终 30 源均有可评输出。21 条开发已见与 9 条新增用户声明来源分别报告，不把它们称作全部未见的随机独立测试集。

## 主要结果

| 指标 | 评价者 A | 评价者 B | 对应解释 |
| --- | ---: | ---: | --- |
| 首尾均完整 | 82/141（58.16%） | 52/141（36.88%） | 两个边界项都为“是”；均低于任务书第 9 页的 85% 自检目标 |
| 五项全部通过 | 70/141（49.65%） | 46/141（32.62%） | 前五项全部为“是”；这是更严格的描述指标，不与 85% 混比 |
| 所选 Top5 接受 | 78/141（55.32%） | 75/141（53.19%） | “愿意保留”为“是”；均低于第 10 页约 60% 的参考值 |

上述为实际产出片段加权的比例，每源最多五条，未填槽位不当作人工否定。按 30 个来源各自比例再等权平均，A／B 首尾均完整为 58.89%／35.11%、五项完整为 49.89%／31.11%、接受为 55.67%／51.33%，仅作补充描述。同源片段可能重叠，不能将 141 段视为 141 份独立原视频；未给出独立样本置信区间。

任务书第 11–12 页将这些数值定位为进度、自检参照，并非实习通过门槛。低 κ 如实报告，不通过删片、合并答案或改标签提高数值。

## 一致性与逐题结果

主要一致性为“是／否／不确定”三类 nominal Cohen κ，汇合 141 条原始配对后计算，保留不确定，不平均六组 κ。接受判断一致 **97/141＝68.79%**，κ＝**0.375792**。公式为 `(Po − Pe)/(1 − Pe)`，本轮 `Pe=0.500075449`。yes-vs-rest 的敏感性 κ＝0.385901，不替换三类主结果。

| A 的接受判断＼B 的判断 | 是 | 否 | 不确定 |
| --- | ---: | ---: | ---: |
| 是 | 55 | 23 | 0 |
| 否 | 20 | 42 | 0 |
| 不确定 | 0 | 1 | 0 |

55 条得到两人接受，43 条仅一人接受，43 条无人回答“是”；这只是意见重叠，不是裁定后的标准答案，也不把“不确定”等同于“否”。

| 题项 | A：是／否／不确定 | B：是／否／不确定 | 三类 κ |
| --- | ---: | ---: | ---: |
| 开头完整 | 129 / 12 / 0 | 99 / 42 / 0 | 0.2316 |
| 结尾完整 | 89 / 52 / 0 | 64 / 77 / 0 | 0.5430 |
| 可以独立理解 | 134 / 7 / 0 | 112 / 26 / 3 | 0.0382 |
| 没有无关内容 | 127 / 14 / 0 | 84 / 55 / 2 | 0.0982 |
| 事件连贯 | 112 / 29 / 0 | 86 / 55 / 0 | 0.2179 |
| 愿意保留 | 78 / 62 / 1 | 75 / 66 / 0 | 0.3758 |

结尾完整是两位评者在前五项中共同最多的否定项：A 52 条、B 77 条。B 对无关内容、连贯性及开头也给出更多否定；两人接受比例接近并不表示对相同片段达成一致。题项差异提示后续复核重点，尚不能单凭表格断言是 ASR、分句还是选段算法造成。

## 结论与后续

本轮默认 `sentence-window-v1 + rule-v1`、时间 NMS IoU 0.5、边界优化关闭，保留原排名每源最多 Top5。它衡量的是所选输出质量与人评一致性，不能从这一已筛选集合计算全池排序 AUC、召回率，或声称 LLM 优于规则。此前开发样本的 [Rule／LLM 配对诊断](SCORE_DIAGNOSTICS.md) 单独保留。

下一步优先复核结尾失败与分歧案例，区分“半句被截断”“事件未讲完”“依赖片段外上下文”；如修改生成或边界策略，必须另记为开发修正，再用新冻结素材评价。本批原答案、默认规则和原统计保持，未根据反馈重新调分或选片。正式报告采用“可运行、可复核、可人工精修；默认自动选段质量仍有明显不足”的结论。

第七周其他系统交付与未测项见 [系统核对](WEEK7_SYSTEM_CHECK.md)。本轮没有新增参考标注 CER／镜头 F1、未参与校准字幕的独立测时或隔离 CPU／GPU 完整端到端性能，不能由双人人评补齐这些数字。
