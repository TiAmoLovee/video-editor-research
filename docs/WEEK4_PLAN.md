新增 `clipforge.decision.candidates`、草案 Schema 和来源校验。先验证冻结的 analysis 0.1.0，再以每个句子单元为起点、每个后续句子单元为终点枚举合规窗口，步长为一个单元。沿用 normalized_video 时间轴。
