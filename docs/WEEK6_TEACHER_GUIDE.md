# 第六周工作台使用与验收

第六周功能位于原 ClipForge 工作台的同一个任务详情页。原有上传、分析、话题候选、整段回答、画面适配及字幕修时继续保留。

## 打开与操作

线上演示入口以仓库首页的实际部署链接为准。演示需要访问密码，请向项目作者索取；密码不会保存在公开仓库。项目作者本机入口为 `http://127.0.0.1:8200/`，这个地址不能在另一台电脑上直接访问项目作者的工作台。

1. 选择一个已经完成分析且具有候选的历史任务。较早的任务只有原下载功能，保留原样。
2. 点击转写中的句子，检查视频定位；播放试听后填写操作人姓名，查看候选评分和理由，记录采纳或驳回。
3. 勾选需要进入成片的候选，调整顺序并保存剪辑清单。采纳决定与加入成片分别记录。
4. 在人工编辑中输入时码或源帧，调整入出点、增删或重排，另存新版本。刷新后可以回读保存结果。
5. 选定保存版本，生成 MP4，或按最终片段生成逐片 ZIP。完整画面竖屏与居中裁切版本也保留各自的画面设置，导出不会使用未保存草稿。
6. 打开人工操作记录，核对姓名、时间、片段和修改前后值；可下载审计 JSON。

姓名由操作者填写，不代表已认证的个人身份。演示入口由访问密码保护，访问者使用同一套任务库。

## 演示入口的运行条件

当前教师演示方案从项目作者电脑提供服务，需要电脑和 Docker 保持运行并联网。临时 HTTPS 域名在隧道重建后会变化，不承诺长期在线；改变入口后须同步更新仓库首页。建议演示上传文件小于 100 MB。
