# Shotcut 工程样本

## 样本信息

- 工程文件：Week1Work.mlt
- 创建软件：Shotcut 26.8.1
- 原始素材：Sucai1.mp4
- 工程分辨率：960 × 600
- 工程帧率：30 fps

## 实验内容

将原视频分割，移除中间部分，在 V1 视频轨道上依次保留两个片段：

| 顺序 | 原素材开始位置 | 原素材结束位置 |
|---|---|---|
| 1 | 00:00:00.000 | 00:00:20.000 |
| 2 | 00:00:30.600 | 00:00:41.233 |

表中的结束位置包含结束帧。剪辑后的工程总时长约为 30.700 秒。

## 打开方法

1. 准备 Shotcut、Week1Work.mlt 和原始素材 Sucai1.mp4。
2. 使用 Shotcut 打开 Week1Work.mlt。
3. 工程当前引用的素材路径为：
   C:/Users/asus/Desktop/Sucai/Sucai1.mp4
4. 如果素材位置不同，需要在 Shotcut 中重新定位素材。
5. 打开后，检查 V1 轨道上是否有两个连续排列的片段，并播放检查。

`.mlt` 文件保存素材引用和剪辑安排，不包含原视频本身。
